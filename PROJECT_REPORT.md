# Project Report

## Title
Women Safety Application

## Objective
To create a privacy-aware Python safety assistant that helps users prepare emergency alerts, manage trusted contacts, share a location link, check in safely, and record incidents.

## Problem
During an unsafe situation, a user may need to communicate quickly with trusted people and provide useful location information.

## Solution
The application combines trusted-contact management, location-link generation, emergency message creation, safety check-ins, and incident logging in one modular Python application.

## Scope
This version is a GitHub-ready educational prototype. Actual SMS/GPS automation depends on platform permissions and an authorized provider.

## Future Scope
Android integration, encrypted storage, push notifications, authentication, cloud synchronization, and optional wearable support.
